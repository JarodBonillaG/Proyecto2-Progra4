# Frontend — Bolsa de Empleo

React frontend built with Vite for the Bolsa de Empleo academic project.

## Requirements

- Node.js and npm
- The backend API running at `http://localhost:8080`

## Available commands

Install dependencies:

```sh
npm install
```

Run the local development server:

```sh
npm run dev
```

Create a production build:

```sh
npm run build
```

Preview the production build locally:

```sh
npm run preview
```

The Vite development server proxies `/api` requests to the backend at `http://localhost:8080`. See the repository root README for the full project overview and local setup.
